# Customer Segmentation with K-Means
## Overview

This repository contains a Python-based customer segmentation workflow using K-Means clustering.

The project explores customer demographics, contract characteristics, and product attributes to identify distinct customer segments and analyze their profitability.

The analysis is based on a real-world business use case. Due to confidentiality restrictions, the original dataset and analytical results are not included.

## Methodology

The workflow consists of three stages:

- Data Preparation: Data filtering, cleaning, feature selection, and preparation for analysis.

- Exploratory Data Analysis (EDA): Analysis of customer demographics, product characteristics, profitability, correlations, and temporal trends.

- K-Means Clustering: Feature scaling, categorical encoding, PCA visualization, cluster evaluation using Silhouette Scores, and cluster profiling.
